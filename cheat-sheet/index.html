Output, input and variables

See lessons on print, variables and input.

print("Hello", name, sep=", ", end="\n")   # show values
name = input("Your name? ")                # always returns text

x += 1                                     # same as x = x + 1

Strings

See strings and string methods.

s = "Hello, World"
print(len(s), s[0], s[-1], s[0:5], s[::-1])
print(s.upper(), s.lower(), s.replace("World", "India"))
print(s.split(", "), "-".join(["a", "b"]), "  hi ".strip())
print(s.find("World"), s.count("l"), s.startswith("He"), "lo" in s)
n = 3.14159
print(f"{s} has {len(s)} characters; pi is {n:.2f}")

Output

12 H d Hello dlroW ,olleH
HELLO, WORLD hello, world Hello, India
['Hello', 'World'] a-b hi
7 3 True True
Hello, World has 12 characters; pi is 3.14

Decisions

See if, elif and else.

marks = 68
if marks >= 75:
    grade = "A"
elif marks >= 50:
    grade = "B"
else:
    grade = "C"
print(grade, "pass" if marks >= 33 else "fail")

Output

B pass

Loops

See while loops and for loops.

for i in range(3):            # 0 1 2
    print(i, end=" ")
for i in range(2, 11, 4):     # 2 6 10
    print(i, end=" ")
print()
n = 3
while n > 0:
    n -= 1
    if n == 1:
        continue              # skip the rest of this round
    print("n is", n)
for number, name in enumerate(["Asha", "Ravi"], 1):
    print(number, name)

Output

0 1 2 2 6 10 
n is 2
n is 0
1 Asha
2 Ravi

break leaves a loop at once. continue jumps to the next round.

Lists

See lists and sorting and slicing.

a = [5, 2, 9]
a.append(7)            # add at the end
a.insert(0, 1)         # add at a position
a.remove(2)            # remove by value
last = a.pop()         # remove and return the last
a.sort()               # sort in place
print(a, last, len(a), sum(a), min(a), max(a))
print(sorted(a, reverse=True), a[:2], a[-1], 9 in a, a.index(9))
print([x * 2 for x in a if x > 1])

Output

[1, 5, 9] 7 3 15 1 9
[9, 5, 1] [1, 5] 9 True 2
[10, 18]

Dictionaries

Functions

See functions and arguments and scope.

def area(length, width=1):
    """Return the area of a rectangle."""
    return length * width

print(area(4, 5), area(4), area(width=2, length=3))

Classes

See classes and objects.

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def passed(self):
        return self.marks >= 33

s = Student("Asha", 78)
print(s.name, s.passed())

Output

Asha True

Five habits that prevent most beginner bugs

  1. Indent with four spaces, never tabs, and keep every line of a block level.
  2. Remember that input gives text. Convert before doing maths.
  3. Counting starts at 0, and the stop value of a range or slice is not included.
  4. = stores, == compares.
  5. Methods such as sort and append change the list and return None. Do not assign their result.
