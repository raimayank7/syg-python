Modules and import

Python comes with a large collection of ready-made code called the standard library. It is split into modules, each about one subject: maths, random numbers, dates, files and many more. A module is brought into your program with import. Learning to use modules means you stop writing things that already exist.

Importing a module

import math

print(math.sqrt(144))
print(math.pi)

Output

12.0
3.141592653589793

After import math, everything inside the module is reached with the module name and a dot. By custom, imports go at the very top of the file.

Other ways to import

from math import sqrt, pi
print(sqrt(81), pi)

import datetime as dt
print(dt.date(2026, 1, 26).year)

Output

9.0 3.141592653589793
2026
  • from module import name brings in just the names you list. You then use them without the prefix.
  • import module as short gives the module a shorter nickname.

Avoid from math import *, which brings in everything. It hides where each name came from and can quietly replace your own variables.

ceil is handy for questions such as "how many buses for 130 children if a bus holds 40?".

import math

The random module

random makes programs unpredictable: games, quizzes, picking a winner. The output below will differ every time you run it, so these examples first call random.seed(1). A seed makes the "random" choices repeat, which is useful for testing. Leave it out in real programs.

import random
random.seed(1)

print(random.randint(1, 6))
print(random.choice(["Asha", "Ravi", "Meena"]))
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(cards)
print(random.sample(range(1, 50), 3))

Output

2
Meena
[4, 2, 5, 3, 1]
[49, 29, 31]
NameWhat it does

random.choice(list)one item picked from a list

random.sample(items, k)k different items

Note that randint includes both ends, unlike range. One warning: this module is for games and simulations. For passwords and anything to do with security, Python has a separate module called secrets.

The datetime module

Dates are harder than they look, with months of different lengths and leap years. Let the module do the work.

import datetime

republic = datetime.date(2027, 1, 26)
today = datetime.date(2026, 11, 12)
print(republic - today)
print((republic - today).days, "days to go")
print(republic.strftime("%d %B %Y"))
print(republic.strftime("%A"))

Output

75 days, 0:00:00
75 days to go
26 January 2027
Tuesday

Subtracting two dates gives the gap between them. strftime turns a date into text using format codes.

CodeMeaningExample
%dday of the month26
%mmonth as a number01
%Bmonth nameJanuary
%Yyear2027
%Aday of the weekTuesday

The example above uses a fixed date so that its output stays the same. For the real current date, call datetime.date.today().

To move forwards or backwards in time, add a timedelta.

import datetime

start = datetime.date(2026, 11, 12)
due = start + datetime.timedelta(days=45)
print(due)
print(due.strftime("%d/%m/%Y"))

Output

2026-12-27
27/12/2026

Finding out what a module offers

Two built-in functions help you explore. dir(module) lists the names inside it. help(module.name) prints the explanation written by its authors. The complete reference is the official documentation at docs.python.org.

import math
names = [n for n in dir(math) if not n.startswith("_")]
print(len(names), "names, such as", names[:5])

Output

62 names, such as ['acos', 'acosh', 'asin', 'asinh', 'atan']

Modules beyond the standard library

Thousands of extra packages exist for web work, data and more. They are installed with a tool called pip. As a beginner you do not need any of them. Everything in these lessons uses only what comes with Python.

Do not name your file after a module

If you save your own program as random.py or math.py, then import random loads your file instead of the real module, and nothing works. Choose a different file name. This mistake produces a confusing AttributeError.

Try it yourself

Exercise 3. How many days are there between 15 August 1947 and 26 January 1950?

Show one answer

print(gap.days)

Output
