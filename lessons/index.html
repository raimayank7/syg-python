How the stages fit together

Basics gets you printing, storing values in variables, doing sums, handling text and asking the user questions. By the end of it you can write a small calculator-style program that asks for values and prints an answer.

Decisions and loops is where programs come alive. With if a program can choose. With while and for it can repeat. Most people find that this is the stage where programming first feels powerful, and also where the first real confusion appears. Take it slowly and do every exercise.

Collections covers lists, tuples, sets and dictionaries: the ways Python keeps many values together. Real programs are mostly about data, and these four types hold nearly all of it.

Functions and modules teaches you to package code under a name, pass values in, get results out, and use the large library that comes with Python.

Going further adds files, error handling, list comprehensions and a first look at classes. After this stage you can read most beginner-level Python code that you meet elsewhere.

Tips for steady progress

  • Do not skip the exercises. Reading feels like learning, but only writing code shows what you have understood.
  • If a lesson does not make sense, go back one lesson, not forward. The gap is nearly always just behind you.
  • Keep your practice files. Name them after the lesson, such as lesson09_while.py. Looking back at them after a month shows how far you have come.
  • When all the lessons carry a tick, move to the projects and the full list of practice questions.
