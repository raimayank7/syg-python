How to use these questions

To revise: pick a topic you finished some days ago and try its three questions without opening the lesson. If you can do all three, the topic has stayed with you. If not, reread that lesson's examples, close it, and try again tomorrow.

To practise daily: do three questions a day from different topics. Mixing topics is harder than doing one topic in a block, and that extra effort is what makes knowledge last.

To go further: after solving a question, change it. Make the list longer, the limit different, the input wrong. Ask "what if the list is empty?" or "what if the number is negative?" and make your program cope.

Checking your answer

Run your program and compare what it prints with the output shown under our answer in the lesson. Your code can look quite different from ours and still be right. There are many ways to write most programs. Once yours works, read our version too, because seeing a second way to solve the same problem is one of the quickest ways to learn.

If your program stops with an error, read the last line of the message and look it up in the errors section.

When single questions feel easy, move on to the small projects, where one program grows over several stages.
